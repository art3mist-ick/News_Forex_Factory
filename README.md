## 4. Key Rules for Trading High-Impact Releases

1. **Relative to Forecast:** Green does not inherently mean "Buy" and Red does not mean "Sell." Green indicates the number beat expectations, while Red means it missed expectations.
2. **Deviation Gap:** The larger the gap between the **Actual** and **Forecast** figures, the greater the price volatility.
3. **Data Revisions:** Check the **Previous** column for a revision icon. A strong current figure can be muted if the previous month's value was revised downwards significantly.
4. **Multiple Simultaneous Drops:** When multiple major news items release at the same minute, look for alignment across core figures (e.g., both PPI and Retail Sales coming in Green) before establishing a clear direction.
